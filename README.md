# All Service Pro Website

Simple static site for All Service Pro (landscaping & property maintenance).

## Files
- `index.html` — main page
- `styles.css` — styles
- `script.js` — mobile menu + smooth scroll
- Logo images (upload these):
  - `logo-black.jpg` — black background logo (recommended for header)
  - `logo-bright.jpg` — lime green logo
  - `business-card.jpg` — optional business card image

## How to use
1. Upload the logo images to the root of this repo (same names).
2. Enable GitHub Pages (Settings → Pages → Deploy from branch → main / root).
3. Site will be live at https://dgshonk.github.io/allservicepro/
4. Later connect to Cloudflare Pages or custom domain when ready.
